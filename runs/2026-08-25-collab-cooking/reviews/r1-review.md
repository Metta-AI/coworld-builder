  `tests/test_manifest.py:125`.
- Observed: `coworld==0.1.42` — the exact pin in `.github/workflows/coworld-release.yml:74` — validates
  the template *before* it touches docker (`coworld/bundle.py:38-44`, `_load_template_manifest`). Running
  that function on this file:
  ```
  4 validation errors for Coworld Manifest
  game.owner        Field required
  game.display_name Extra inputs are not permitted ('Collaborative Cooking')
  version           Extra inputs are not permitted ('0.1.0')
  replay_viewer     Extra inputs are not permitted ({'bundle': 'static-replay-viewer'})
  ```

  `cogame-babel` templates returns **OK** with `game.replay_viewer = bundle='static-replay-viewer'`.

  this repo is the only one that puts it at the top level. The package reads it only from `game`:
  `coworld/bundle.py:81` (`manifest.game.replay_viewer` — the gate that invokes
  `tools/build_replay_viewer.sh`), `coworld/upload.py:927` (`manifest["game"].get("replay_viewer")` —
  the gate that uploads the bundle), `coworld/certifier.py:602`, `coworld/cli.py:1274`. The shipped

### O3 — the pause branch is an unbounded loop that skips the deadline guard
- Where: `src/collab_cooking/coworld/live_episode.py:412-439`, with the guard at `:436-438`;
  reachable from `src/collab_cooking/coworld/server.py:163-174` (`handle_global_message`, command
  `pause`/`stop`) and `:237-242` (`_drain_global_messages`, which accepts any JSON frame on `WS /global`).
- Observed:
  ```python
  while self.sim.current_step < self.config.max_steps and not self.sim.is_done():
      if self.paused:
          await asyncio.sleep(0.05)
          continue
      ...
      if self._deadline_reached():        # step 10 — only reached when NOT paused
          await self._settle("deadline")
  ```
  `self.paused` is only cleared by another `/global` control frame. While paused the loop never evaluates
  `_deadline_reached()`, never advances `sim.current_step`, and never settles; the process runs until the
  platform kills it, and no `results.json`/`replay.json` is written. Every *other* wait I traced is
  bounded (see "Traced and consistent"), so this is the single unbounded path.
- Note says: §Degrade, never hang — "Nothing in the tick loop blocks on an unbounded read", and step 10 is
  specified as an unconditional per-tick guard anchored at process start. §Global protocol says the socket
  "accepts the starter's control messages (`play`/`pause`/`speed`)" but does not exempt the guard.
- Checklist item: 5 (*Degrade-never-hang* — "there is no unbounded loop or blocking read"; category `hang`).
- Why blocking: a single `{"type":"control","command":"pause"}` frame from anything that connects to
  `/global` — the certification runner's own ping target — stops the episode for ever with no artifacts
  and no exit. Whether the hosted runner ever sends such a frame I could not determine (see "Could not
  determine"); the loop is unbounded either way. *(observed; reachability inferred)*
