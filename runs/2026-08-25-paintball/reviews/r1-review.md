### F9 — provider response bodies reach the replay through a byte-index slice
`src/paintball/llm.nim:164` (`response.body[0 .. min(response.body.high, 400)]`), `:172` and `:177`
(`… 300`) build the `LlmError` message from a **byte** slice of an arbitrary provider body; that message becomes
`error.msg` at `decide.nim:377-378` and is written to the replay as `fallback.detail` after
`truncateRunes(MaxFallbackDetailRunes)` (`decide.nim:233`). `truncateRunes` (`directives.nim:57-64`) only
shortens; it cannot repair a codepoint the byte slice cut in half, so a non-ASCII error body at the cut can put
invalid UTF-8 into the chat stream. Design §Reply schema: "slicing a `string` by byte index on any path to the
replay is **forbidden**"; AGENTS.md repeats it. Every *other* recorded string is rune-safe and tested
(`tests/test_directives.nim:88-110`, emoji on the boundary + `validateUtf8`).

### F10 — the attempt-1 transport deadline is 5 s, not 4.5 s

### F11 — `turnSpacingMs` is a blocking sleep on the game loop
`src/paintball/decide.nim:316-319` calls `os.sleep(...)` (bounded by `turnSpacingMs`, 5000 ms in every shipped
variant) inside `turn`, which the server invokes on the loop thread before stepping the tick
